# Ionic-App "Buchabfrage" #

<br>

Diese Repository enthält ein [Ionic](https://ionicframework.com/)/Angular-Projekt
für eine mobile App, die die Details für ein Buch anhand der eingegebenen
[ISBN13](https://de.wikipedia.org/wiki/Internationale_Standardbuchnummer#ISBN_13)
von einer Web-API abruft.
